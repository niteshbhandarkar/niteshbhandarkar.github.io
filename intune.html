What is Intune?

Intune is Microsoft's cloud-based endpoint management platform used to manage devices, applications, security policies and compliance.

Key Concepts

  • Enrollment
  • Compliance Policy
  • Configuration Profile
  • Application Deployment
  • Windows Autopilot

Intune vs SCCM

SCCM Intune
On-Premises Management Cloud-Based Management
Requires SCCM Infrastructure Managed from Microsoft Cloud
Strong OS Deployment Strong MDM/MAM
Configuration Manager Client MDM Enrollment

Co-Management

Co-management allows a Windows device to be managed by both SCCM and Microsoft Intune simultaneously.

Benefits

  • Gradual Cloud Migration
  • Conditional Access
  • Device Compliance
  • Cloud Visibility
  • Modern Endpoint Management

Cloud Attach

Cloud Attach connects SCCM with Intune and allows organizations to leverage modern cloud-based management.

  • Tenant Attach
  • Co-Management
  • Cloud Visibility
  • Remote Actions
  • Autopilot Integration

Windows Autopilot

Windows Autopilot enables zero-touch deployment of Windows devices. Users can receive a new laptop, sign in with company credentials, and automatically receive company applications and policies.

Interview Questions

What is Intune?

Intune is a cloud-based endpoint management solution.

What is SCCM?

SCCM (MECM) is Microsoft's on-premises endpoint management platform.

What is Co-Management?

Co-management allows SCCM and Intune to manage the same device.

What is Cloud Attach?

Cloud Attach connects SCCM and Intune for modern endpoint management.
